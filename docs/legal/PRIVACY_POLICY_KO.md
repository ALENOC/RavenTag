## 3. 처리되는 데이터 및 기술 아키텍처

### 3.1 기기에 로컬로 저장되는 데이터 (개발자 또는 ElectrumX로 절대 전송되지 않음)

다음 민감 데이터는 암호화되어 기기에만 생성·저장되며 개발자 서버나 ElectrumX 서버로 절대 전송되지 않습니다:

| 데이터 항목 | 목적 | 저장 위치 |
|---|---|---|
| BIP39 니모닉 구문 (시드 구문) | 지갑 생성 및 복구 | Android Keystore (AES-256-GCM) |
| 개인 키 (파생, 암호화됨) | 로컬 트랜잭션 서명 | Android Keystore (AES-256-GCM) |
| 지갑 주소 (RVN) | 로컬 표시 및 계산 | 암호화된 로컬 저장소 |
| 관리자/운영자 키 (Brand 버전) | 로컬 자산 관리 | Android Keystore (AES-256-GCM) |
| 앱 설정 및 환경설정 | 로컬 앱 설정 | 보호된 로컬 설정 |

**사용자의 시드 구문과 개인 키는 절대로 기기를 벗어나지 않습니다.**

### 3.2 NFC 태그 검증 시 전송되는 데이터 (API 백엔드)

제품 정품 검증을 위해 NFC 태그를 스캔할 때 앱은 다음 파라미터를 API 백엔드로 전송합니다:

| 데이터 항목 | 목적 |
|---|---|
| 자산 이름 (예: BRAND/PRODUCT#001) | Ravencoin 블록체인상의 자산 식별 |
| 암호화된 NFC 카운터 (파라미터 e) | SUN MAC 암호화 검증 |
| NFC MAC 값 (파라미터 m) | SUN MAC 암호화 검증 |
| 기기의 IP 주소 | 서버 측 요청 제한(rate limiting) 및 네트워크 보안 |

**개발자 백엔드 로그 보존 기간**: IP 주소 및 API 백엔드 네트워크 로그는 최대 30일간 보존되며(백엔드 로그 정리 미들웨어 코드 수준에서 확인됨) 이후 자동 영구 삭제됩니다.

**법적 근거 (GDPR)**: 인프라 보안 확보, 남용 방지 및 사이버 공격 완화를 위한 정당한 이익 (GDPR 제6조(1)(f)).

### 3.3 블록체인 및 ElectrumX 작업 중 처리되는 데이터

앱이 잔액 조회, 거래 내역 조회 또는 트랜잭션 전송을 수행할 때 ElectrumX 인프라와 통신합니다.

**A. ElectrumX 서버가 관찰하거나 수신할 수 있는 데이터:**
공개 ElectrumX 서버는 다음 접속 데이터 및 메타데이터를 관찰할 수 있습니다:
- 기기의 출처 IP 주소
- TLS 접속 메타데이터, 타임스탬프, 요청 빈도
- JSON-RPC 프로토콜 쿼리 및 스크립트 해시 조회
- 잔액 요청, 거래 내역 및 UTXO 정보
- 트랜잭션 ID (TxID) 및 자산 메타데이터
- 전송을 위해 제출된 이미 서명된 원시 트랜잭션 (raw signed transactions)

조회 패턴에 따라 이러한 정보는 네트워크 식별자(IP 주소 등)와 공개 블록체인상의 활동 간의 기술적 연관성을 가능하게 할 수 있습니다.

> **명확한 보안 고지:**
> 개인 키와 시드 구문은 ElectrumX 서버에 절대로 필요하지 않으며 일반적인 지갑 작동의 일부로 전송되지 않습니다.

**B. 트랜잭션 생성 및 서명 워크플로:**
지갑에서 실행되는 모든 트랜잭션에 대해:
1. 사용자가 앱 화면에서 트랜잭션을 시작합니다.
2. 앱이 기기에서 로컬로 원시 트랜잭션을 생성합니다.
3. 사용자가 독점 관리하는 개인 키를 사용하여 기기에서 암호화 서명이 수행됩니다.
4. 앱이 서명된 트랜잭션을 ElectrumX 서버로 전송합니다.
5. ElectrumX가 서명된 트랜잭션을 Ravencoin Core 노드로 중계·전송(relay/broadcast)하여 블록 포함을 요청합니다.

ElectrumX 인프라는 사용자의 개인 키를 보유하지 않으며, 독자적으로 유효한 서명을 생성할 수 없고, 수신자나 금액을 결정하지 않으며, 수탁 계좌를 유지하지 않습니다.

**C. 공개 Ravencoin Core 노드의 역할:**
공개 Ravencoin Core 노드는 블록체인 동기화, 블록 및 트랜잭션 검증, P2P 전파 등의 인프라 기능만 수행합니다. 고객 자금을 보관하거나 개인 키를 소유하지 않습니다.

### 3.4 자산 이미지 로드 (IPFS 게이트웨이)
IPFS에 호스팅된 자산 이미지를 표시하기 위해 앱은 공개 IPFS 게이트웨이(예: ipfs.io, cloudflare-ipfs.com)에 연결될 수 있습니다.

### 3.5 카메라 및 NFC 데이터
- **카메라**: 기기에서 실시간 QR 코드 판독용으로만 사용됩니다.
- **NFC**: 판독은 로컬에서 수행되며 파생된 검증 파라미터(asset, e, m)만 전송됩니다.

### 3.6 수집하지 않는 데이터
개발자는 성명, 이메일 주소, 하드웨어 식별자(IMEI), 위치 정보 또는 상업적 추적 텔레메트리를 수집하지 않습니다.

## 11. 규제 틀 및 MiCA 용어 고지

RavenTag는 비수탁형(자체 수탁형) 오픈 소스 소프트웨어로 설계 및 배포됩니다. 개발자는 이용자의 개인 키를 보유하지 않고, 이용자의 암호 자산(RVN 또는 토큰)에 대한 통제권이나 수탁권을 행사하지 않으며, EU 규정 2023/1114 (MiCA)에 따른 암호 자산 수탁 또는 관리 서비스를 제공하지 않습니다. 개발자의 ElectrumX 인프라 활동은 오픈 프로토콜상에서 네트워크 데이터 및 서명된 트랜잭션을 기술적으로 중계하는 것에 국한됩니다.
