## 3. 처리되는 데이터 및 기술 아키텍처

### 3.1 기기에 로컬로 저장되는 데이터

다음 민감 데이터는 로컬 기기에서 생성 또는 저장되도록 설계되며 정상적인 지갑 동작을 위해 ElectrumX 서버에 제공될 필요가 없습니다.

| 데이터 | 목적 | 예정 저장 위치 |
|---|---|---|
| BIP39 니모닉(시드 구문) | 지갑 생성 및 복구 | Android Keystore / 보호된 로컬 저장소 |
| 파생 개인 키 | 로컬 거래 서명 | Android Keystore / 보호된 로컬 저장소 |
| RVN 지갑 주소 | 표시 및 지갑 작업 | 로컬 저장소 |
| 관리자/운영자 키(해당하는 경우) | Brand 기능 | 보호된 로컬 저장소 |
| 설정 및 환경설정 | 앱 구성 | 로컬 환경설정 |

**개인 키와 시드 구문은 정상적인 지갑 동작 중 ElectrumX 서버로 전송되지 않습니다.**

### 3.2 NFC 검증 및 API 백엔드

NFC 태그를 검증할 때 앱은 다음과 같은 검증에 필요한 기술 데이터를 백엔드로 전송할 수 있습니다.

| 데이터 | 목적 |
|---|---|
| 자산 이름 | Ravencoin 블록체인상의 자산 식별 |
| 암호화된 NFC 카운터 / 검증 파라미터 | 암호학적 검증 |
| NFC MAC 값 | 암호학적 검증 |
| IP 주소 | 보안, 남용 방지, rate limiting 및 기술적 요청 관리 |

백엔드 로깅 미들웨어는 **HTTP 메서드, 경로, 상태 코드, 처리 시간 및 IP 주소**와 같은 요청 메타데이터를 기록합니다. 요청 또는 응답 본문은 기록하지 않습니다. 이 메타데이터는 보안, 남용 방지, rate limiting, 기술 진단 및 집계 운영 메트릭에 사용될 수 있습니다.

**코드에서 확인된 보존:** 애플리케이션 테이블 `request_logs` 및 `rate_limit_events`에 영구 저장된 레코드는 30일보다 오래된 레코드를 자동 삭제하는 루틴의 대상입니다.

이 루틴은 콘솔/stdout, 컨테이너, 운영체제, reverse proxy, CDN, 호스팅 제공자 또는 ElectrumX 프로세스 로그를 관리하지 않습니다. 이러한 로그의 보존 여부와 기간은 실제 운영환경 구성에 따라 달라지며, 본 방침에서는 확인되지 않은 고정 보존기간을 제시하지 않습니다.

**법적 근거:** 해당되는 경우 개발자가 운영하는 인프라에서 기술 메타데이터를 처리하는 근거는 GDPR 제6조 제1항 (f)의 정당한 이익으로, 인프라 보안, 남용 방지, rate limiting, 기술 진단 및 비례적인 운영 모니터링을 목적으로 합니다.

### 3.3 블록체인 및 ElectrumX 작업

앱이 잔액, 거래 내역, UTXO 조회 또는 거래 전송을 수행할 때 ElectrumX 서버와 통신합니다.

ElectrumX 서버는 요청에 따라 다음 정보를 기술적으로 관찰하거나 수신할 수 있습니다.
- 출발지 IP 주소
- 타임스탬프, 요청 빈도 및 연결 메타데이터
- JSON-RPC 및 script-hash 쿼리
- 잔액, 거래 내역 및 UTXO 요청
- 거래 식별자 및 블록체인 메타데이터
- 브로드캐스트를 위해 제출된 이미 서명된 raw transaction

질의 패턴은 네트워크 식별자와 공개 블록체인 활동 사이의 상관관계를 가능하게 할 수 있습니다.

**거래 생성 및 서명:** 거래는 사용자가 시작하고 앱이 구성하며, 사용자가 통제하는 키로 기기에서 서명됩니다. ElectrumX는 이미 서명된 거래를 수신하여 Ravencoin 네트워크로 중계할 수 있습니다. ElectrumX는 사용자의 개인 키를 보유하지 않고, 수신자나 금액을 독자적으로 결정하지 않으며, 사용자를 위한 수탁 계좌를 유지하지 않습니다.

### 3.4 Ravencoin Core 노드
Ravencoin Core 노드는 동기화, 검증 및 P2P 전파와 같은 네트워크 인프라 기능을 수행합니다. 이러한 이유만으로 사용자의 개인 키를 보유하거나 RavenTag 지갑의 수탁 계좌를 유지하는 것은 아닙니다.

### 3.5 IPFS 게이트웨이 및 외부 콘텐츠
앱은 이미지와 메타데이터를 불러오기 위해 IPFS 게이트웨이 또는 기타 외부 리소스를 사용할 수 있습니다. 이러한 서비스 운영자는 자체 관행에 따라 IP 주소 및 기타 네트워크 메타데이터를 수신할 수 있습니다.

### 3.6 카메라 및 NFC
- **카메라:** QR 코드 판독을 위해 기기에서 사용되며, 이 기능을 위해 이미지를 백엔드로 전송할 필요가 없습니다.
- **NFC:** 판독은 기기에서 이루어지며 위에서 설명한 검증에 필요한 파라미터만 백엔드로 전송됩니다.

### 3.7 개발자가 의도적으로 수집하지 않는 데이터
일반적인 앱 사용을 위해 개발자는 이름, 신분증, 우편주소, IMEI, Android Advertising ID 또는 정밀 위치정보를 요구하지 않습니다. 그러나 IP 주소와 기타 네트워크 메타데이터가 인프라에서 처리되는 경우 개인정보가 될 수 있다는 점은 변하지 않습니다.

## 6. 데이터 보존

- **지갑의 로컬 데이터:** 지갑 삭제, 앱 데이터 삭제 또는 앱 제거 시까지 기기 동작에 따라 보존됩니다.
