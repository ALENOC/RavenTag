## 3. 処理データと技術構成
### 3.1 ローカルのウォレットデータ
シードフレーズ、秘密鍵その他の機密ウォレット認証情報は端末上で生成・保存される設計です。通常のウォレット動作では秘密鍵およびシードフレーズは ElectrumX に送信されません。

### 3.2 NFC 検証と API バックエンド
NFC 検証では、アセット名、暗号化 NFC カウンタ/検証パラメータ、NFC MAC、IP アドレスが送信される場合があります。

バックエンドのリクエスト logger は **HTTP メソッド、パス、ステータスコード、処理時間、IP アドレス**を記録し、リクエスト本文またはレスポンス本文は記録しません。これらはセキュリティ、不正利用防止、rate limiting、技術診断、集約された運用メトリクスに利用される場合があります。

**コードで確認できる保存期間：** `request_logs` と `rate_limit_events` の永続レコードは、30日を超えると自動削除ルーチンの対象となります。

このルーチンは **console/stdout、コンテナ、OS、reverse proxy、CDN、ホスティング事業者、ElectrumX プロセスのログ**を管理しません。これらの保存期間は実際の本番設定に依存し、確認できない固定期間を本ポリシーでは断定しません。

適用される場合、開発者インフラによる技術メタデータ処理は、セキュリティ、不正利用防止、rate limiting、診断、比例的な運用監視のため GDPR 6(1)(f) の正当な利益に基づくことがあります。

### 3.3 Blockchain と ElectrumX
ElectrumX は要求内容に応じ、送信元 IP、時刻、接続メタデータ、JSON-RPC/script-hash クエリ、残高/履歴/UTXO 問合せ、トランザクション ID、署名済み raw transaction を観察または受信する場合があります。問合せパターンから公開 blockchain 活動との関連付けが可能になる場合があります。

取引はユーザーが開始し、本アプリが端末上で構築し、ユーザーが管理する鍵で署名します。ElectrumX は署名済み取引を Ravencoin ネットワークへ中継できますが、ユーザーの秘密鍵を保有せず、受取人や金額を独自に決定せず、ユーザーのカストディ口座を維持しません。

### 3.4 Ravencoin Core、IPFS、カメラ、NFC
Ravencoin Core ノードは同期、検証、P2P 伝播などを行いますが、それ自体により RavenTag ユーザーの秘密鍵を保有するものではありません。IPFS 等の外部サービスは独自の慣行に従い IP/ネットワーク情報を処理する場合があります。QR 読取および NFC 読取は端末上で行われ、必要な検証パラメータのみバックエンドへ送信されます。

## 4. 通常利用で意図的に要求しないデータ
通常利用では、氏名、本人確認書類、住所、IMEI、Android Advertising ID、正確な位置情報を要求しません。ただし IP アドレス等のネットワークメタデータは個人データとなる場合があります。

## 5. セキュリティと非カストディ構成
実装上提供されるローカル保護および暗号化通信を使用しますが、絶対的安全性を保証するものではありません。非カストディ構成では、開発者は通常、ユーザー資産を復元・移動するための鍵を保有しません。

## 6. 保存期間
- ローカルウォレットデータ：端末/App の削除動作に従います。
- `request_logs` / `rate_limit_events`：30日超のレコードを自動削除。
- runtime/console、proxy、OS、CDN、hosting、ElectrumX ログ：実際のデプロイ設定に依存。
- Ravencoin blockchain：分散複製された公開データは開発者が一方的に削除できません。
