## 3. 処理されるデータと技術アーキテクチャ

### 3.1 お客様のデバイス上にローカル保管されるデータ（開発者や ElectrumX に送信されることはありません）

以下の機密データは、お客様のデバイス上に暗号化された状態で生成・保管され、開発者のサーバーや ElectrumX サーバーに送信されることは一切ありません：

| データ項目 | 目的 | 保管場所 |
|---|---|---|
| BIP39 助記記号（シードフレーズ） | ウォレットの生成および復元 | Android Keystore (AES-256-GCM) |
| プライベートキー（派生、暗号化済み） | ローカルでのトランザクション署名 | Android Keystore (AES-256-GCM) |
| ウォレットアドレス (RVN) | ローカル表示および計算 | 暗号化ローカルストレージ |
| 管理者/オペレーターキー（Brand版） | ローカルでの資産管理 | Android Keystore (AES-256-GCM) |
| アプリ設定および基本設定 | ローカルアプリ設定 | 保護されたローカル設定 |

**お客様のシードフレーズおよびプライベートキーがデバイス外に送信されることは絶対にありません。**

### 3.2 NFC タグ検証時に送信されるデータ（API バックエンド）

製品の真贋を検証するために NFC タグをスキャンする際、本アプリは以下のパラメータを API バックエンドに送信します：

| データ項目 | 目的 |
|---|---|
| アセット名（例：BRAND/PRODUCT#001） | Ravencoin ブロックチェーン上のアセット識別 |
| 暗号化 NFC カウンター（パラメータ e） | SUN MAC 暗号検証 |
| NFC MAC 値（パラメータ m） | SUN MAC 暗号検証 |
| デバイスの IP アドレス | サーバー側のレート制限およびネットワークセキュリティ |

**開発者バックエンドのログ保存期間**：IP アドレスおよび API バックエンドのネットワークログは最大 30 日間保存され（バックエンドログクリーンアップミドルウェアのコードレベルで確認済み）、その後自動的に永久削除されます。

**法的根拠（GDPR）**：インフラストラクチャのセキュリティ確保、乱用防止、サイバー攻撃緩和のための正当な利益（GDPR 第6条(1)(f)）。

### 3.3 ブロックチェーンおよび ElectrumX 操作時に処理されるデータ

本アプリが残高照会、履歴参照、またはトランザクションの送信を実行する際、ElectrumX インフラストラクチャと通信します。

**A. ElectrumX サーバーが観察または受信する可能性のあるデータ：**
パブリック ElectrumX サーバーは、以下の接続データおよびメタデータを観察する可能性があります：
- デバイスの送信元 IP アドレス
- TLS 接続メタデータ、タイムスタンプ、リクエスト頻度
- JSON-RPC プロトコルクエリおよびスクリプトハッシュ照会
- 残高リクエスト、トランザクション履歴、UTXO 情報
- トランザクション ID (TxID) およびアセットメタデータ
- 送信のために提出された署名済み生トランザクション (raw signed transactions)

クエリパターンによっては、これらの情報がネットワーク識別子（IP アドレスなど）とパブリックブロックチェーン上のアクティビティとの技術的関連付けを可能にする場合があります。

> **明確なセキュリティ開示：**
> プライベートキーおよびシードフレーズは ElectrumX サーバーには決して必要ではなく、通常のウォレット操作の一部として送信されることはありません。

**B. トランザクションの作成および署名ワークフロー：**
ウォレットによって実行されるすべてのトランザクションについて：
1. ユーザーがアプリ画面からトランザクションを開始します。
2. アプリがデバイス上でローカルに生トランザクションを構築します。
3. ユーザーが独占的に管理するプライベートキーを使用し、デバイス上で暗号署名が行われます。
4. アプリは署名済みのトランザクションを ElectrumX サーバーに送信します。
5. ElectrumX は署名済みトランザクションを Ravencoin Core ノードへ中継・ブロードキャスト（relay/broadcast）し、ブロックチェーンへの記録を依頼します。

ElectrumX インフラストラクチャはユーザーのプライベートキーを保有しておらず、独自に有効な署名を作成することはできず、受取人や金額を決定することもなく、暗号資産を預かるカストディ口座を維持することもありません。

**C. パブリック Ravencoin Core ノードの役割：**
パブリック Ravencoin Core ノードは、ブロックチェーンの同期、ブロックおよびトランザクションの検証、P2P 通信および伝播というインフラ機能のみを実行します。顧客の資金を保持したり、アカウントを管理したり、プライベートキーを所有したりすることはありません。

### 3.4 アセット画像の読み込み（IPFS ゲートウェイ）
IPFS 上にホストされているアセット画像を表示するため、本アプリはパブリック IPFS ゲートウェイ（例：ipfs.io, cloudflare-ipfs.com）に接続する場合があります。

### 3.5 カメラおよび NFC データ
- **カメラ**：QR コードのリアルタイム読み取りのみにデバイス上で使用されます。
- **NFC**：読み取りはローカルで実行され、派生した検証パラメータ（asset, e, m）のみが送信されます。

### 3.6 収集しないデータ
開発者は、氏名、メールアドレス、ハードウェア識別子（IMEI）、位置情報、または商業追跡テレメトリを収集することはありません。

## 5. データセキュリティとセルフカストディ型アーキテクチャ

デバイス上の機密データは Android Keystore を介した AES-256-GCM 暗号化によって保護されています。開発者インフラとのネットワーク通信は暗号化された HTTPS/TLS チャネルを使用します。

---

## 6. データの保存期間（保存の制限）

- **デバイス上のデータ**：ウォレットの削除またはアプリのアンインストールまで保存。
- **開発者バックエンドのログ**：最大 30 日間保存（自動クリーンアップコードに準拠）後、永久削除。
- **開発者 ElectrumX ログ**：診断およびセキュリティに必要な最小限の期間保存。
- **パブリック Ravencoin ブロックチェーンデータ**：ブロックチェーン上に確認されたトランザクションは永久に公開され、変更や削除はできません。
