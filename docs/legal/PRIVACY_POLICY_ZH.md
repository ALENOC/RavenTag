## 3. 处理的数据与技术架构

### 3.1 本地存储在您设备上的数据（切勿传输给开发者或 ElectrumX）

以下敏感数据在您的设备上以加密形式生成并存储，切勿传输给开发者运营的任何服务器或 ElectrumX 服务器：

| 数据项 | 目的 | 存储位置 |
|---|---|---|
| BIP39 助记词（Seed Phrase） | 钱包生成与恢复 | Android Keystore (AES-256-GCM) |
| 私钥（派生、已加密） | 本地交易签名 | Android Keystore (AES-256-GCM) |
| 钱包地址 (RVN) | 本地显示与计算 | 加密本地存储 |
| 管理员/操作员密钥（Brand 版） | 本地资产管理 | Android Keystore (AES-256-GCM) |
| 应用设置与偏好 | 本地应用配置 | 受保护的本地偏好 |

**您的助记词和私钥绝不会离开您的设备。**

### 3.2 NFC 标签验证期间传输的数据（API 后端）

当您扫描 NFC 标签以验证产品真实性时，本应用会将以下参数发送至 API 后端：

| 数据项 | 目的 |
|---|---|
| 资产名称（例如 BRAND/PRODUCT#001） | Ravencoin 区块链上的资产识别 |
| 加密 NFC 计数器（参数 e） | SUN MAC 加密验证 |
| NFC MAC 值（参数 m） | SUN MAC 加密验证 |
| 您设备的 IP 地址 | 服务器端速率限制（rate limiting）与网络安全 |

**开发者后端日志保留期**：IP 地址和 API 后端网络日志最多保留 30 天（已在后端日志清理中间件的代码级别确认），之后自动永久删除。

**法律依据 (GDPR)**：正当利益（GDPR 第 6(1)(f) 条），用于确保基础设施安全、防止滥用和缓解网络攻击。

### 3.3 区块链及 ElectrumX 操作期间处理的数据

当本应用执行余额查询、交易历史检索或广播交易时，会与 ElectrumX 基础设施进行通信。

**A. ElectrumX 服务器可能观察或接收的数据：**
公共 ElectrumX 服务器可能观察到以下连接数据和元数据：
- 设备源 IP 地址；
- TLS 连接元数据、时间戳和请求频率；
- JSON-RPC 协议查询和脚本哈希检索；
- 余额请求、交易历史和 UTXO 信息；
- 交易标识符 (TxID) 和资产元数据；
- 提交用于广播的已签名原始交易（raw signed transactions）。

根据查询模式，这些信息在技术上可能允许将网络标识符（如 IP 地址）与公共区块链上的活动关联起来。

> **明确安全声明：**
> ElectrumX 服务器绝不需要私钥和助记词，在正常钱包操作中也不会将其作为一部分进行传输。

**B. 交易创建与签名工作流：**
对于钱包执行的每笔交易：
1. 用户在应用界面发起交易；
2. 本应用在设备本地构建原始交易；
3. 使用用户独家控制的私钥在设备上进行加密签名；
4. 本应用将已签名的交易发送至 ElectrumX 服务器；
5. ElectrumX 将已签名的交易中继/广播（relay/broadcast）至 Ravencoin Core 节点以包含在区块中。

ElectrumX 基础设施不拥有用户的私钥，不能独立生成有效签名，不决定收款人或金额，也不托管资金。

**C. 公共 Ravencoin Core 节点的角色：**
公共 Ravencoin Core 节点仅执行基础设施功能（区块链同步、区块与交易验证、P2P 传播）。它不持有客户资金，也不拥有私钥。

### 3.4 资产图像加载（IPFS 网关）
为了显示托管在 IPFS 上的资产图像，本应用可能会连接到公共 IPFS 网关（例如 ipfs.io, cloudflare-ipfs.com）。

### 3.5 摄像头与 NFC 数据
- **摄像头**：仅在设备上用于实时二维码读取。
- **NFC**：读取在本地进行；仅传输派生的验证参数（asset, e, m）。

### 3.6 我们不收集的数据
开发者不收集姓名、电子邮件地址、硬件标识符（IMEI）、位置数据或商业追踪遥测数据。

## 5. 数据安全与非托管架构

设备上的敏感数据通过 Android Keystore 支持的 AES-256-GCM 加密进行保护。与开发者基础设施的网络通信使用加密的 HTTPS/TLS 通道。

---

## 6. 数据保留（存储限制）

- **设备数据**：保留至钱包删除或应用卸载。
- **开发者后端日志**：最多保留 30 天（符合自动清理代码），之后永久删除。
- **开发者 ElectrumX 日志**：仅保留诊断和安全所需的最低限度时间。
- **公共 Ravencoin 区块链数据**：区块链上已确认的交易为永久公开，不可修改或删除。
